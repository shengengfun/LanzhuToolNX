## 本次更新

### AVS 外部滤镜：终于能导入了

- AVS 页的「已加载的外部滤镜 / 脚本」新增「**导入滤镜**」按钮：选 `.dll` / `.avsi` / `.avs`（可多选）→ 复制进 `tools/avs/plugins` → 清单立刻刷新，dll 顺手把 `LoadPlugin("…")` 插到脚本开头。
  以前只能自己往目录里丢文件 —— 页面上唯一的文件选择框是「载入脚本」，只认 `.avs`，dll 根本选不进来。
- 新增「**刷新**」按钮：手动往目录里丢完文件，点一下重新扫描，不用重启。
- 同名文件按覆盖处理（同一个滤镜换新版），挑的正好是目录里那一个时跳过。

### 修：压制页启动时不再挂着上次压制的视频

- 修好了「启动后压制页还是显示上一部片子」：读设置文件时没有抹掉「这一趟」的字段，老版本留下的源文件 / 输出 / 字幕路径会被原样填回表单；
  而落盘时又按 `VOLATILE_FIELDS` 抹掉了，于是文件看着是干净的、界面上却一直挂着那个陈旧路径。
  现在**回填时同样清掉**，只恢复参数 —— 和 1.3.7 说明里写的「压制 / 封装 / 抽取不再记上次的文件」一致。

## English

### AVS external filters can finally be imported

- The "loaded external filters / scripts" box on the AVS page has a new "**import filter**" button: pick `.dll` / `.avsi` / `.avs` (multi-select) → the files are copied into `tools/avs/plugins`, the list refreshes immediately, and dlls get their `LoadPlugin("…")` inserted at the top of the script.
  Until now you had to drop files into the folder yourself — the only file picker on the page ("load script") accepted `.avs` alone, so a dll could not be selected at all.
- New "**refresh**" button: re-scans the folder after you drop files in by hand, no restart needed.
- Same-name files are overwritten (upgrading a filter); picking the file that already sits in the folder is a no-op.

### Fix: the encode page no longer starts with the previous video

- Fixed "after launch the encode page still shows the last video": when the settings file was read, the "this run" fields were not stripped, so source / output / subtitle paths left over from an older version were filled back into the form.
  Saving always stripped them, so the file looked clean while the UI kept showing the stale path.
  The restore path now strips them the same way and only restores parameters — matching what the v1.3.7 notes promised.
