## 本版改动

### 新功能：插帧超分

侧边栏新增一页（排在 AVS 之后），插帧与超分可以只开一个，也可以一起开。

**两套引擎，按需选：**

| | 插帧 | 超分 | 需要下载 |
| --- | --- | --- | --- |
| 内置滤镜 | 运动补偿插值（minterpolate） | Lanczos / xBR / hqx | 不需要 |
| 本地模型 | **RIFE** | **Real-ESRGAN** / **Real-CUGAN** | 约 43～411 MB |

- 本地模型走 **ncnn + Vulkan**，**独立 exe + 权重文件，不需要 CUDA、Python 或 PyTorch** ——
  Intel / AMD / NVIDIA 的核显都能跑。
- 插帧支持 **2× / 3× / 4× 倍数**，也可以直接指定目标帧率（例如 24 → 60）；
  超分支持 **2× / 3× / 4×**，也可以额外指定最终分辨率。
- Real-CUGAN 可选三档模型与 0～3 级降噪，动画片源效果最好。
- 输出文件自动命名，后缀写明用了什么：`1.mp4` → `1_rife2x_cugan2x.mp4`，
  重名会自动退到 `1_new_file(1)_rife2x_cugan2x.mp4`，不会覆盖源文件。
- 音轨可选复制 / 转 AAC / 不要。

**关于速度（想先说清楚）**：
本地模型要把视频拆成图片序列再逐帧推理，比普通压制慢得多。
实测在一台核显机器上，7.5 秒的 640×480 短片：RIFE 2 倍补帧约 16 秒，
Real-CUGAN 2 倍超分约 11 分钟。**建议先用一段短片确认效果和速度**；
处理过程中会占用与「帧数 × 分辨率」同一量级的临时磁盘空间。

### 设置 → 工具获取

- 新增三个模型包：**RIFE（插帧）**、**Real-ESRGAN（超分）**、**Real-CUGAN（超分）**。
- RIFE 官方包把 11 个模型全打在一起（411 MB），安装后程序会**自动只保留用得到的
  `rife-v4.6` 与 `rife-anime`**，实际占用约 75 MB。

### 界面

- 插帧超分页会实时显示源信息、预计输出分辨率 / 帧率 / 总帧数，
  以及每个本地模型的安装状态与可用权重。
- 帮助页更新日志补上本版条目。
