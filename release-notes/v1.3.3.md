# 岚珠工具箱 v1.3.3

修掉两个让任务根本跑不起来的缺陷，并把自定义主题色的三根滑条做成带渐变轨道的样式。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10/11 x64 | `LanzhuToolNX_1.3.3_x64-setup.exe` | 安装包，双击即可，不需要管理员权限 |

> **系统要求**：Windows 10 / 11 x64 + WebView2 运行时（新版系统已自带）
> ⚠️ 安装包不含 `tools/`（FFmpeg 一套 640MB）。首次运行到 **设置 → 工具获取** 下载，或用离线包导入。
> **SHA256**：见 Release 资产里的 `SHA256SUMS.txt`

## 本版改动

### 修复

- **点「开始」不再报错**：1.3.2 里所有页面的执行按钮都会失败并提示
  `invalid args 'commands' ... expected a sequence`，任务根本发不出去。现在压制、转码、封装、抽取、粗剪都能正常启动。
- **输出文件路径不再粘连**：自动生成的输出名以前会丢掉一个反斜杠，
  生成 `D:\Trans片名.mp4` 这种把目录名和文件名黏在一起的路径。
  受影响的页面：视频压制（自动输出名 / 批量输出目录）、封装、封装转换、常用、粗剪、抽取。

### 界面

- 自定义主题色的 R / G / B 三根滑条重做：轨道改成**渐变**，
  左端是「该通道拉到 0」、右端是「拉到 255」，滑块里填当前结果色 ——
  拖动之前就能看出会变成什么颜色。同时补上键盘操作（`←` `→`、`PgUp` `PgDn`、`Home` `End`）
  与无障碍语义（读写屏会念成「R 通道，当前 246，0 到 255」）。
