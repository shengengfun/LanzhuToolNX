## 本次更新

### 进度显示

- 修好了「压制过程中进度一动不动」：ffmpeg 的进度行以回车（`\r`）结尾，之前被当成"没有换行"整段卡住，所以日志里只有开头的压制参数。现在日志会像原版一样实时刷出 `frame= … time= … speed= …`。
- **进度不再画在底栏那条横贯整屏的长条上** —— 底栏只留一句"压到哪个文件了、多少 %"，进度本体挪到 Windows 任务栏的图标上（绿色进度条），暂停变黄、失败变红，切到别的程序也能一眼看到进展。

### 记住上次的设置

- 视频、音频、AVS、插帧超分的**参数**与上次停留的页面会保留，重开就回到原样。
- **压制 / 封装 / 抽取不再记上次的文件**：每次压的基本都是不同的片子，留着一个指向上一部片子的陈旧路径只会碍事。
- 这些属于「上次用的参数」，和「偏好设置」分开保存 —— 点「重置所有设置」不会把它们清掉。

### AVS 界面补全

- 补齐原版 AVS 页的功能：源视频 / 字幕 / 脚本路径 / 输出四个路径框、**生成 / 清空 / 预览 / 保存 / 载入**，以及 Undot · Tweak · Levels · LanczosResize · Sharpen · Crop · AddBorders · Trim 八组滤镜（勾上即按原版 `GenerateAVS()` 的顺序重算脚本）。
- 底栏新增「**已加载的外部滤镜 / 脚本**」清单：直接列出 `tools/avs/plugins` 里的 dll 与 avsi，点一条 dll 就把 `LoadPlugin("…")` 插到脚本开头，并显示 AviSynth.dll 是否就绪。
- 新增「**应用到常规压制全局**」：勾上后「视频」页的每个文件都会先过这份脚本 —— 画面走脚本里的滤镜链，音轨仍从源文件抽，不会把声音弄丢。

### 即开即用

- 启动画面不再硬停：设置读完立刻退场（原来最少要等 550ms），设得快的机器上它根本不会出现。
- 工具目录体检（要递归扫一遍 800MB 的 `tools/`）挪到界面出来之后的空闲时间，不再卡在首帧上。

### 窗口行为

- 点右上角的 ✕ **直接退出**，不再悄悄躲进托盘让人找不到窗口。
- 新增「**托盘模式**」：勾上之后关窗 / 最小化都把窗口收进任务栏托盘，长任务可以放心跑。

## English

### Progress

- Fixed the frozen progress during encoding: ffmpeg terminates its progress lines with a carriage return, which the reader treated as "no newline", so the log only ever showed the initial command. The log now streams `frame= … time= … speed= …` live, like the original.
- The long full-width progress bar at the bottom is gone. The status bar keeps a one-line "which file, how many %", and the real progress is drawn on the **Windows taskbar button** (green, amber when paused, red on failure).

### Remembered settings

- Video, audio, AVS and enhance **parameters** plus the last visited page are restored on the next launch.
- **Encode / mux / extract no longer remember the last files** — every job uses a different source, and a stale path only gets in the way.
- These are stored separately from preferences, so "Reset all settings" keeps them.

### AVS page

- The original AVS tab is complete again: source video / subtitle / script path / output pickers, **generate / clear / preview / save / load**, and the eight filter groups (Undot · Tweak · Levels · LanczosResize · Sharpen · Crop · AddBorders · Trim) that rebuild the script in the original `GenerateAVS()` order.
- A new "**loaded external filters / scripts**" box lists the dll/avsi files in `tools/avs/plugins`; clicking a dll inserts its `LoadPlugin("…")`, and the AviSynth.dll presence is shown.
- New "**apply to regular encoding globally**" switch: every file on the Video page goes through this script first — the picture uses its filter chain while audio is still taken from the source file, so nothing is lost.

### Instant start

- The splash screen no longer holds for a minimum 550 ms; it leaves as soon as settings are loaded, and on a fast machine never appears at all.
- The tools-directory health check (a recursive walk over the 800 MB `tools/`) is deferred until after the UI is up.

### Window behaviour

- Closing with ✕ now **exits the app** instead of silently hiding to the tray.
- New "**tray mode**": when enabled, closing or minimizing puts the window in the taskbar tray so long jobs keep running.
