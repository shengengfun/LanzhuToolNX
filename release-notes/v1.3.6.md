## 本次更新

### 进度显示

- 修好了「压制过程中进度一动不动」：ffmpeg 的进度行以回车（`\r`）结尾，之前被当成"没有换行"整段卡住，所以日志里只有开头的压制参数。现在日志会像原版一样实时刷出 `frame= … time= … speed= …`。
- 底栏与输出区的「任务」页签现在显示真实百分比、当前正在处理的文件、已编码帧数与速度。
- Windows 任务栏图标上会显示压制进度条，暂停时变黄、失败时变红，切到别的程序也能一眼看到进展。

### 记住上次的设置

- 视频、音频、封装、抽取、AVS、插帧超分的参数与路径，以及上次停留的页面，退出后都会保留，重开就回到原样。
- 这些属于「上次用的参数」，和「偏好设置」分开保存 —— 点「重置所有设置」不会把它们清掉。

### 界面

- 部分下拉框的文字会被挤成 `H....`：现在把下拉框字号与其它控件对齐（同屏不再一大一小）。
- 字幕框恢复原版的「双击清空」；双击视频 / 输出框用默认程序打开对应文件。
- 换视频时会重新寻找同名字幕（`.ass` / `.srt` / `.ssa` / `.sub`），找不到就清空，不会再把上一部片子的字幕留下来。
- 启动画面不再显示"正在准备工具链"：现在窗口一出现就盖住空白，设置读完立刻退场，不再白等一秒多。
- GPU 型号只探测一次并缓存，冷启动少一次 PowerShell 启动开销。

## English

### Progress

- Fixed the frozen progress during encoding: ffmpeg terminates its progress lines with a carriage return, which the reader treated as "no newline", so the log only ever showed the initial command. The log now streams `frame= … time= … speed= …` live, like the original.
- The status bar and the "Task" tab now show a real percentage, the file being processed, encoded frames and speed.
- The Windows taskbar button shows a progress bar, turning amber when paused and red on failure.

### Remembered settings

- Video, audio, mux, extract, AVS and enhance parameters (including paths) plus the last visited page are restored on the next launch.
- These are stored separately from preferences, so "Reset all settings" keeps them.

### Interface

- Dropdowns that were squeezed into `H....` now use the same font size as the rest of the form.
- Double-clicking the subtitle box clears it again; double-clicking the video/output box opens that file.
- Replacing the source video re-detects the matching subtitle file and clears the old one when none is found.
- The splash screen no longer claims to be "preparing the toolchain"; it covers the blank window and leaves as soon as settings are loaded.
- The GPU list is probed once and cached, removing one PowerShell start-up from the cold start path.
